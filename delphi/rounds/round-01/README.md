# Round 01 — first panel consultation

Two questionnaires, answered in LimeSurvey:

- `survey_q1_geometry.txt`: questionnaire 1, geometry panel (wiki page `Q1R1pt` / `Q1R1en`);
- `survey_q2_applications.txt`: questionnaire 2, applications panel (wiki page `Q2R1pt` / `Q2R1en`).

Both files are generated by `scripts/limesurvey_build.py`; see
`delphi/limesurvey/README.md` for how to run the round.

After the round closes, this folder receives the pseudonymous panel data
(`respondents.csv`, `responses.csv`, `familiarity.csv`, `filter_votes.csv`,
`grades.csv`, `open_answers.csv`, `panel_profile.csv`) and the aggregates
(`weights.csv`, `consensus.csv`, `filter.csv`, `properties.csv`,
`grades_consensus.csv`), with the public-only aggregates in `public/`.
